# AutoPave 自動鋪地

Minecraft Java 26.3 的 Fabric 模組，只需要裝在自己的電腦上（純客戶端），伺服器不用裝任何東西。

框出一塊範圍後打開開關，你在範圍裡走動或飛行時，它會自動把身邊的空格補上你手上的方塊。

## 安裝

1. 安裝 [Fabric Loader](https://fabricmc.net/use/)，選 26.3 版
2. 把 [Fabric API](https://modrinth.com/mod/fabric-api) 的 26.3 版放進 `.minecraft/mods`
3. 到本 repo 的 **Releases → latest** 下載 `autopave-x.y.z.jar`，也放進 `mods`

## 用法

| 按鍵 | 功能 |
|---|---|
| `[` | 設定角落 1：準星指著的位置，也就是你按右鍵會放方塊的那一格。這一格的高度就是鋪設的高度 |
| `]` | 設定角落 2：高度自動跟著角落 1 |
| `O` | 開始／停止 |

按鍵可以在「選項 → 控制 → 按鍵綁定 → AutoPave 自動鋪地」更改。

**鋪 128×128 的鵝卵石：**

1. 站在預定的角落，看著地面按 `[`
2. 面向要鋪的方向，輸入 `/autopave square 128`，就會往前方和右手邊各延伸 128 格
3. 把鵝卵石拿在主手，按 `O` 開始
4. 在範圍裡來回走（或飛）。快捷欄的鵝卵石用完時，它會自動從背包補一組上來；整個背包都用完就會停下來提醒你補貨

### 指令

- `/autopave pos1 [x y z]`、`/autopave pos2 [x z]`：用座標設定角落
- `/autopave square <邊長>`：從角落 1 往前方和右手邊各延伸指定格數
- `/autopave speed <1–20>`：設定每秒放幾格，預設 8。伺服器有反作弊插件時，建議調到 6 以下
- `/autopave on`、`/autopave off`、`/autopave clear`、`/autopave status`

## 限制（刻意這樣設計）

- 不會自動移動你的角色
- 只會放在原版伺服器允許的距離以內
- 每一格都要貼著已經存在的方塊，所以懸空的平台要從靠著地面或牆壁的那一邊開始鋪
- 方塊只會從你自己的背包拿

在別人的伺服器上使用前，請先問過服主。
